# DIGITAL ATTENDANCE SYSTEM
## EEE227 – Mid Semester Capstone Project
### Programme: HND Electrical Engineering (Level 200)

---

## 📌 Project Overview

This project is a console-based Digital Attendance System developed using C++.  
It is designed to replace the traditional paper-based attendance system used in lecture halls.

The system allows lecturers to:

- Register students
- Create lecture sessions
- Mark attendance (Present, Absent, Late)
- Update attendance records
- Generate attendance reports
- Automatically store data using text files

The application runs offline on Windows and uses file handling for persistent storage.
